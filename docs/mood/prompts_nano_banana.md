# RoninShell: moodboard con Nano Banana

Paleta base: negro carbón (#0b0d0e), dorado envejecido (#c9a24a), verde teal (#1f8f8a / #3fd6c4 para el brillo), metal cepillado gris oscuro.
Idea común: la pantalla del juego es la pantalla de un **cyberdeck** (ordenador portátil artesanal, hecho de piezas), con marco físico.

Consejo: genera 3-4 variantes de cada prompt, guarda las que te gusten en `docs/mood/` con un nombre claro (por ejemplo `A_deck_frontal_1.png`) y dime cuáles. Yo las uso como referencia.
